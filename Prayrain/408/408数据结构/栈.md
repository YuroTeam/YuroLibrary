栈是一个受限的顺序表。
对于同一个入栈序列，如果我们规定的操作序列不同，那么出栈序列也会不同。所以在没有限定操作序列的前提下，**入栈序列和出栈序列会呈现一对多的关系**

而这个对应的关系有如下规律：
如果有n个元素入栈。那么会有多少种不同的出栈方式？
答案：**卡特兰数**
即$\frac{1}{n+1} C^n_{2n}$  这个答案是由排列组合得到的
其中$C^n_{2n} = \frac{A^n_{2n}}{(n!)}$


栈的ADT如下：

```C
ADT Stack {
    数据对象 (Data):
        D = { a_i | a_i ∈ ElemType, i = 1, 2, ..., n, n >= 0 }
        
    数据关系 (Relation):
        R = { <a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n }
        约定 a_1 为栈底，a_n 为栈顶。
        
    基本操作 (Operations):
        InitStack(&S)
            操作结果：构造一个空栈 S。
            
        DestroyStack(&S)
            初始条件：栈 S 已存在。
            操作结果：销毁栈 S，释放内存。
            
        ClearStack(&S)
            初始条件：栈 S 已存在。
            操作结果：将栈 S 清为空栈。
            
        StackEmpty(S)
            初始条件：栈 S 已存在。
            操作结果：若栈 S 为空栈，返回 TRUE，否则返回 FALSE。
            
        StackLength(S)
            初始条件：栈 S 已存在。
            操作结果：返回 S 的元素个数（栈的长度）。
            
        GetTop(S, &e)
            初始条件：栈 S 已存在且非空。
            操作结果：用 e 返回 S 的栈顶元素。
            
        Push(&S, e)
            初始条件：栈 S 已存在。
            操作结果：插入元素 e 为新的栈顶元素（入栈）。
            
        Pop(&S, &e)
            初始条件：栈 S 已存在且非空。
            操作结果：删除 S 的栈顶元素，并用 e 返回其值（出栈）。
            
        StackTraverse(S, visit())
            初始条件：栈 S 已存在。
            操作结果：从栈底到栈顶依次对 S 的每个元素调用 visit()。
} ADT Stack
```

#### 2.表达式求值
表达式求值有三种方式：
* 逆波兰表达式求值（后缀表达式）
* 前缀表达式求值
* 中缀表达式转逆波兰式（后缀表达式）

##### 逆波兰表达式：
特点：表达式中的符号全部被后置
例子：(中缀)  $5 + 8  \rightarrow 58+$ (后缀)

如何转换成逆波兰表达式：
遵循 **操作数1 + 操作数2 + 运算符**

如: $(3 + 4 ) \times 5 - 6$
括号内先算， 3 4 +
随后算x 5,于是3 4 +是操作数1,5是操作数2
得到 3 4 + 5 x
最后同理的到 3 4 + 5 x 6 -

逆波兰表达式求值的含义：
已知一个后缀表达式，如何利用计算机计算出他的实际运算出来的值

逆波兰表达式求值的过程：
* 遇到操作数即压栈
* 遇到操作符即将栈顶的两个元素取出进行计算，并将结果压栈

##### 前缀表达式
特点：表达式中的符号全部被前置（和逆波兰式相反）
例子：(中缀)  $[(1+2)\times3]+[(4\div(6-2))\times5] \rightarrow +\times+123 \times\div4-625$ (后缀)


如何转换成前缀表达式：
遵循 **运算符 + 操作数1 + 操作数2**
操作数的顺序不能改变

前缀表达式求值的过程：
* 遇到操作数即压栈
* 遇到操作符即将栈顶的两个元素取出进行计算，并将结果压栈 **但此时的扫描顺序会变成从后往前**

#### 3.使用栈来进行表达式求值

计算方法：
* 建立一个空栈
* 开始扫描表达式
* 如果遇到操作数：直接输出，不做栈操作
* 如果遇到运算符：依次弹出栈中优先级大于等于当前运算符的所有运算符并输出，碰到左括号“（”或栈空停止。随后当前运算符入栈
* 如果遇到界限符：遇到左括号“（”，入栈；遇到右括号“）”，依次弹出栈中运算符并输出，直到左括号“（”弹出为止
* 按上述方法处理完所有字符后，将栈中剩余运算符依次弹出并加入后缀表达式


#### 4.数制转换
数制转换的目标是：对于输入的任意一个非负x进制整数，打印与其等值的y进制数

方法：
* 对于一个十进制数N需要转换为d进制数，计算N%d，将结果压栈
* 计算N= N/d 重复上一步骤，直至N为0
* 元素依次出栈，即为等值的数制转换结果
