链表的ADT如下：
```C
ADT LinkedList {
    数据对象 (Data):
        D = { a_i | a_i ∈ ElemType, i = 1, 2, ..., n, n >= 0 }
        
    数据关系 (Relation):
        R = { <a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2, ..., n }
        
    基本操作 (Operations):
        InitList(&L)
            操作结果：构造一个空的线性链表 L。
            
        DestroyList(&L)
            初始条件：链表 L 已存在。
            操作结果：销毁链表 L，释放内存。
            
        ClearList(&L)
            初始条件：链表 L 已存在。
            操作结果：将链表 L 重置为空表。
            
        ListEmpty(L)
            初始条件：链表 L 已存在。
            操作结果：若 L 为空表，返回 TRUE，否则返回 FALSE。
            
        ListLength(L)
            初始条件：链表 L 已存在。
            操作结果：返回 L 中数据元素的个数。
            
        GetElem(L, i, &e)
            初始条件：链表 L 已存在，且 1 <= i <= ListLength(L)。
            操作结果：用 e 返回 L 中第 i 个数据元素的值。
            
        LocateElem(L, e, compare())
            初始条件：链表 L 已存在，compare() 是数据元素判定函数。
            操作结果：返回 L 中第 1 个与 e 满足 compare() 关系的元素的位序。若不存在，返回 0。
            
        PriorElem(L, cur_e, &pre_e)
            初始条件：链表 L 已存在。
            操作结果：若 cur_e 是 L 的元素且不是第一个，用 pre_e 返回其前驱，否则操作失败。
            
        NextElem(L, cur_e, &next_e)
            初始条件：链表 L 已存在。
            操作结果：若 cur_e 是 L 的元素且不是最后一个，用 next_e 返回其后继，否则操作失败。
            
        ListInsert(&L, i, e)
            初始条件：链表 L 已存在，且 1 <= i <= ListLength(L) + 1。
            操作结果：在 L 的第 i 个位置之前插入新元素 e，L 的长度加 1。
            
        ListDelete(&L, i, &e)
            初始条件：链表 L 已存在，且 1 <= i <= ListLength(L)。
            操作结果：删除 L 的第 i 个数据元素，并用 e 返回其值，L 的长度减 1。
            
        ListTraverse(L, visit())
            初始条件：链表 L 已存在。
            操作结果：依次对 L 的每个元素调用 visit() 函数。
} ADT LinkedList

```

#### 链表节点的插入方式
链表节点插入的方式分两种： **前插法** 与 **尾插法**
**前插法**的方式是新增一个节点，将新增节点的next指向首元节点，然后再将头节点的next指向新增节点。最后插入的顺序会是倒序。如 **ABC**节点插入后会变成**CBA**节点

**尾插法**的方式是新增一个**r指针**,这个指针**首先指向最后一个节点**，随后每次都和**新增节点**的地址相同（也就是保证r指针所指向的节点时刻是最后一个节点),随后新增节点的next设为NULL,再把原来的尾节点的next由NULL改为新增节点的地址。最后插入的顺序会是顺序，如**ABC**节点插入后还是**ABC**节点
