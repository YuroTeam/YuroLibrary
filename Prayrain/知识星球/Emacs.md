Emacs 是一款诞生于 1970 年代、以 Lisp 语言为核心的“神级”文本编辑器。它超越了传统编辑器的范畴，通过无限的定制性构建了一个集代码编辑、Org-mode 知识管理、Magit 极速 Git 协作于一体的闭环生态，被无数极客视为一生相伴的“个人操作系统”

Emacs 的底层是一个 Lisp 解释器（Emacs Lisp，简称 Elisp）。这意味着 Emacs 的几乎所有功能（包括光标移动、文本输入、窗口管理）都是用 Elisp 编写的。

你可以在不重启编辑器的情况下，实时修改 Emacs 的代码并立即生效。
这让 Emacs 拥有了无限的定制能力，你可以把它改造成任何你想要的样貌。

很多人留在 Emacs 的唯一原因就是 Org-mode。这是世界上最强大的纯文本任务管理、笔记和排版工具。

    它可以作为个人知识库（类似 Obsidian，但早了十几年）。
    它可以做 GTD（时间管理）、写待办事项、追踪项目进度。
    它可以导出为 PDF、HTML、LaTeX，甚至进行文学编程（Literate Programming）
