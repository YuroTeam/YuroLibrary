# 基础知识

## 导体、绝缘体与半导体

在物理学中，根据材料的导电能力，可以将他们划分**导体**、**绝缘体**和**半导体**。典型的半导体是硅Si和锗Ge，它们都是*4价元素*。

### 本征半导体

**本征半导体就是化学成分纯净且晶体结构完整的半导体晶体**，一般来说制造半导体器件要求半导体材料的纯净度达到 `99.9999999%`，通常说要有 9 个 9。

本征半导体的原子之间会形成共价键，相邻的两个原子会各拿出一个电子，一起共享，以此让**每个原子都形成 8 电子稳定结构**。不过这个图其实只是简化了一下，实际上应该是三维立体的结构，一个原子和相邻的原子构成标准的正四面体。

![[Pasted image 20260614165634.png]]

所以在 **绝对温度 T = 0K 的时候，所有的价电子都被共价键紧紧束缚在共价键中，不会变成自由电子，因此本征半导体的导电能力非常弱，接近绝缘体。**

### 本征激发

**随着温度的升高，或者本征半导体收到了光线的照射，一些电子在吸收了能量以后，可以挣脱原子核的束缚，形成自由电子，从而参与导电，这个现象叫做本征激发或者热激发**。自由电子产生的同时，**在原来的共价键中留下一个空位，称为空穴**，我们称激发的电子和空穴为电子**空穴对**。

外加的能量越高，激发的电子越多，产生的空穴也越多。

![[Pasted image 20260614171452.png]]

**与本征激发相反的现象叫做复合**，自由电子填到空穴里重新形成共价键。**在一定的温度或者光照下，本征激发和复合是同时进行的，达到了动态平衡，此时电子空穴对的浓度是稳定的**。

### 本征半导体的导电机制

**本征半导体的导电是一个动态平衡的过程**，电子带负电，空穴带正电，而电子才是真正发生粒子运动的。**我们将自由电子和空穴称为载流子**：

| 载流子  | 位置  | 运动方式    | 物理本质               | 电流方向  |
| :--- | :-- | :------ | :----------------- | :---- |
| 自由电子 | 导带  | 逆电场方向漂移 | **真正的粒子移动**        | 与电场相反 |
| 空穴   | 价带  | 顺电场方向漂移 | **价电子依次填补空位的等效运动** | 与电场相同 |

所以半导体里的 `总电流 = 电子流 + 空穴流`。

总的来说 **本征半导体的导电性取决于外加能量**，温度变化和光照变化都会影响到本征半导体的导电性。

## 杂质半导体

在本征半导体中掺入某些微量元素以后的半导体称为 **杂质半导体**。

杂质半导体有两种，N 型半导体和 P 型半导体。

- **N 型半导体是给本征半导体掺入五价杂志元素，例如掺入磷元素、砷元素等**，掺入五价元素就多出了自由电子，于是我们说，**N 型半导体里面自由电子是多数载流子，而空穴是少数载流子**。
- **P 型半导体是给本征半导体掺入三价杂质元素，例如掺入硼元素、镓元素等**，掺入三价元素后，自由电子就少了，于是我们说，**P 型半导体里面自由电子是少数载流子，而空穴是多数载流子**。

还有一个概念就是施主与受主离子：

- **施主离子** = “捐出”电子后留下的**正离子**（对应 N 型半导体）
- **受主离子** = “接受”电子后形成的**负离子**（对应 P 型半导体）

| 特征    | 施主离子 (Donor Ion)    | 受主离子 (Acceptor Ion)     |
| :---- | :------------------ | :---------------------- |
| 杂质类型  | V 族元素（如磷P、砷As、锑Sb）  | III 族元素（如硼B、铝Al、镓Ga）    |
| 价电子数  | 5 个（比硅/锗多 1 个）      | 3 个（比硅/锗少 1 个）          |
| 替代位置  | 取代晶格中的四价硅/锗原子       | 取代晶格中的四价硅/锗原子           |
| 成键情况  | 4 个电子参与共价键，多余 1 个电子 | 只有 3 个电子成键，缺少 1 个电子（空位） |
| 电离过程  | 多余电子挣脱束缚 → 成为自由电子   | 从价带捕获一个电子 → 产生一个空穴      |
| 离子电荷  | 带正电 (+)             | 带负电 (-)                 |
| 是否可移动 | 固定不动（被束缚在晶格位置）      | 固定不动（被束缚在晶格位置）          |
| 对应半导体 | N 型半导体              | P 型半导体                  |
