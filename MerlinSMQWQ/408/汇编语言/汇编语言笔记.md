# 汇编语言笔记

因为我使用的电脑是 Mac 所以我会使用 ARM 的汇编，而不是教材常用的 X86，不过计算机组成原理里面也不是很考汇编，主要是为了更好地理解存储、计算等过程，在大脑中建立内存模型和 CPU 模型，这是学习汇编的本质目的。

参考：[在 Apple Silicon Mac 上入门汇编语言](https://evian-zhang.github.io/learn-assembly-on-Apple-Silicon-Mac/)

# 开始前需要了解的基础知识

汇编语言是有一定的学习门槛的，在那之前需要对计算机组成原理有所了解，因为汇编和高级语言是有较大区别的，汇编更加面向计算机硬件，例如处理器、寄存器等，这也是为什么称之为低级语言。
